# Alfred Apple Reminders Workflow

A lightweight Alfred workflow for quickly creating Apple Reminders
directly from Alfred.

## Features

-   **Create a new reminder**\
    Add a reminder using a simple keyword command.

## Usage

``` bash
reminder <name>
```

**Example:**

``` bash
reminder Buy groceries
```

This will create a new reminder in the Apple Reminders app with the
specified name.

## Requirements

-   Alfred (with workflow support)
-   Apple Reminders (macOS)

## Notes

This workflow is intentionally minimal and focused on fast reminder
creation without additional configuration.
